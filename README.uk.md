# Smart Notify

[![Відкрити репозиторій у HACS у твоєму Home Assistant.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=DmytroZamkovyi&repository=smart_notify&category=integration)

Користувацька інтеграція Home Assistant: **одна служба сповіщень** для
скриптів та автоматизацій, а кожна людина сама обирає, **куди** отримувати
сповіщення за кожною категорією.

```yaml
action: notify.smart
data:
  user: person.alice        # необов'язково; можна список
  category: security        # категорія, яку ти створив
  title: Рух у дворі
  message: Камера біля воріт
  data:                     # необов'язково, передається в канал
    image: /local/snapshot.jpg
```

Ні допоміжних сутностей, ні налаштувань у YAML: усе робиться в інтерфейсі.

## Можливості

- Одна служба `notify.smart` зі стандартним інтерфейсом notify
  (`message`, `title`, `data`) плюс `user` і `category`.
- **Канали**: телефони (Companion), Telegram-боти, браузери (HTML5 push) та
  будь-який інший `notify`. У кожного каналу є власник (людина або «Загальний»).
- **Категорії**: створює адмін (безпека, клімат, техніка, ...). У формі дії
  вони з'являються випадним списком.
- **Маршрути** окремо для людини й категорії:
  - вимкнено;
  - надсилати **в кілька каналів одразу**;
  - **резервні канали**, які пробуються по черзі, лише якщо жоден основний не
    спрацював (наприклад, Telegram, потім телефон).
- «Панель HA» (персистентне сповіщення) це звичайний канал на вибір.
- Кожна людина налаштовує свої маршрути на сторінці `/smart-notify`
  (без пункту в боковому меню). Адмін може налаштовувати всіх.
- Тільки штатний інтерфейс: записи з підзаписами, жодного YAML.

## Вимоги

- Home Assistant з підтримкою підзаписів конфігурації (2025.3 і новіше).
  Перевірено на 2026.10.
- Для браузерних сповіщень: інтеграція HTML5 Push Notifications і зовнішня
  HTTPS-адреса.

## Встановлення

HACS: натисни кнопку вгорі сторінки або додай репозиторій вручну:

1. HACS, Інтеграції, три крапки, Власні репозиторії.
2. Додай цей репозиторій, категорія Integration.
3. Встанови Smart Notify і перезапусти Home Assistant.

Вручну:

1. Скопіюй вміст цього репозиторію в папку `smart_notify` усередині
   `config/custom_components/`, щоб існував файл
   `config/custom_components/smart_notify/manifest.json`.
2. Перезапусти Home Assistant.

Далі: Налаштування, Пристрої та служби, Додати інтеграцію, **Smart Notify**.
З'являться два блоки:

- **Smart Notify · Канали**: тут додаються канали.
- **Smart Notify · Категорії**: тут додаються категорії та налаштовуються
  маршрути.

## Налаштування

1. Блок **Канали**, «Додати канал»: що підключити, назва, власник. Один канал
   на кожен телефон, Telegram-бота чи браузер.
   - Власник = людина: канал використовується лише в маршрутах цієї людини.
   - Власник = «Загальний»: канал використовується, коли `notify.smart`
     викликано без `user`.
2. Блок **Категорії**, «Додати категорію»: ідентифікатор (латиниця, цифри,
   `_`) для скриптів і назва.
3. Маршрути, на вибір:
   - кожна людина відкриває `/smart-notify` під своїм обліковим записом
     (він має бути прив'язаний до `person`);
   - або адмін через шестірню блоку «Категорії».

## Правила маршрутизації

- Налаштування категорії: **Як у загальному маршруті**, **Вимкнено** або
  **Надсилати**. У кожної людини є ще загальний маршрут, від якого категорії
  успадковують налаштування.
- **Надсилати**: у всі канали зі списку «Надсилати в» одразу. Канали зі списку
  «Якщо не доставлено» пробуються по черзі в порядку вибору, лише якщо жоден
  основний не спрацював, і зупиняються на першому успішному.
- Нічого не налаштовано: використовується персистентне сповіщення в панелі HA,
  тому повідомлення не губиться мовчки.
- Якщо жоден вибраний канал не спрацював, помилка пишеться в журнал, а
  повідомлення йде в панель HA як останній варіант.
- Без `user`: усі «Загальні» канали; якщо їх немає, усім людям.
- `user: all` надсилає кожній людині.
- Один канал за один виклик не використовується двічі.
- Невідома категорія: попередження в журналі, діють загальні маршрути.
